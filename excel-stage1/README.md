# Cooperative Society Management — Stage 1

Initial Excel 365 desktop foundation for the Cooperative Society Management project.

## Files
- `Cooperative_Society_Stage1.xlsx`: workbook foundation (download from the project package attached in the ChatGPT conversation).
- `V1_Stage1.bas`: VBA helper macros.
- `INSTALL_AND_TEST.txt`: installation and testing checklist.

## Workbook modules
Settings; Members; Share Capital Ledger; Membership Fee Register; Monthly Recovery Entry; General Journal; Cash Book; Trial Balance; Dashboard.

## Important scope boundary
This is Stage 1, not the complete requested production system. It does not yet automate balanced recovery-to-journal posting, loan repayment/interest schedules, RD/FD maturity schedules, welfare benefit claims, bank reconciliation, user permissions, audit trail or statutory audit outputs.

Use fictional data only. The client must approve interest methods, fees, share deductions, dividend rules, accounting heads, financial year, welfare claim rules and receipt numbering. An accountant should validate the chart of accounts and journal treatment before live operation.

Target environment: Microsoft Excel 365 desktop on Windows. Excel Online does not run VBA macros/UserForms.
