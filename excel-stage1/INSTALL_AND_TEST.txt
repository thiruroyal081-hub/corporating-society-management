STAGE 1 INSTALLATION
1. Open Cooperative_Society_Stage1.xlsx in Microsoft Excel desktop on Windows.
2. Review Read Me and Settings. Use fictional data only.
3. Save a copy as Excel Macro-Enabled Workbook (*.xlsm).
4. Press Alt+F11 > File > Import File > select V1_Stage1.bas.
5. Run macros from Developer > Macros: AddNewMember, FindMember, ValidateRecoveryEntry, CheckJournalBalance.
6. Test totals manually and keep backup copies.

IMPORTANT: This is a foundation prototype, not production-ready accounting software. It does not yet automate journal posting, loan interest schedules, deposit maturity, welfare claims, bank reconciliation, user roles, audit trail or statutory audit reports. Client/accountant must approve all policies before live use.
