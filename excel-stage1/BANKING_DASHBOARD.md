# Banking-style dashboard — Stage 1

The Excel workbook's Dashboard sheet has been redesigned as a banking-style management overview.

## Dashboard layout
- Dark navy institutional header with society title and financial overview subtitle.
- KPI cards: total members, net share capital, membership fees, monthly recovery, journal debits and credits.
- Financial control panel: journal difference, trial balance debit/credit totals, recovery entries awaiting review.
- Posting status indicator.
- Quick-access links to Members, Share Ledger, Fee Register, Recovery Entry, Journal, Cash Book, Trial Balance and Settings.
- Recovery allocation table and a bar chart by module.
- Dashboard return links from the operating sheets.

## Data behaviour
The dashboard uses formulas linked to the workbook registers. Values update when the user enters transactions and Excel recalculates. It is a monitoring dashboard, not a substitute for approved accounting statements.

## Important
The current Stage 1 workbook remains a development prototype. Journal posting automation, loan schedules, deposit maturity, welfare claims, bank reconciliation, access control, audit trail and statutory reporting are not yet implemented. Use fictional test data until the client and accountant approve the rules and reconcile the workbook.

Workbook target: Microsoft Excel 365 desktop on Windows.
