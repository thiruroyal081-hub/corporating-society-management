# Stage 1 setup
1. Download and open Cooperative_Society_Stage1.xlsx in Excel 365 desktop on Windows.
2. Review Read Me and Settings. Use fictional data only.
3. Save a copy as Excel Macro-Enabled Workbook (*.xlsm).
4. Press Alt+F11 > File > Import File > select V1_Stage1.bas.
5. Run macros from Developer > Macros: AddNewMember, FindMember, ValidateRecoveryEntry, CheckJournalBalance.
6. Manually reconcile totals and keep backup copies.

IMPORTANT: Foundation prototype only. Automated journal posting, loan interest schedules, deposit maturity, welfare claims, bank reconciliation, user roles, audit trail and statutory audit formats are not yet implemented. Client/accountant must approve rates, rules and chart of accounts before live use.
